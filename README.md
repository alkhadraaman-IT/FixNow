# FixNow 🛠️

تطبيق خدمات متكامل يجمع جميع الحرفيين في مكان واحد، لتسهيل وصول المستخدمين إلى أي خدمة أو حرفي بكل سهولة وسرعة من خلال الهاتف المحمول.

## 💡 فكرة المشروع
يهدف **FixNow** إلى حل المشاكل التقليدية في البحث عن الحرفيين والصيانة، حيث يتيح للمستخدم حجز الخدمة واختيار الحرفي المناسب بدقة وبكل سهولة، دون الحاجة للوقوع في دوامة البحث والسؤال عن شخص ثقة لإصلاح جهاز أو إنجاز مهمة معينة.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

* **التقنية الأساسية:** [Flutter](https://flutter.dev/)
* **إدارة الحالة (State Management):** [Riverpod](https://riverpod.dev/)
* **هندسة البرمجيات (Architecture):** MVVM (Model-View-ViewModel)

---

## 📱 تدفقات التطبيق الرئيسية (Flows)

* **User Session:** إدارة الجلسات وتسجيل الدخول والخروج للمستخدمين.
* **Search:** بحث متقدم وسريع للوصول إلى الحرفيين والخدمات المطلوبة.
* **Favorite:** إمكانية إضافة الخدمات إلى المفضلة للوصول إليها لاحقاً.
* **Cart:** سلة طلبات لحجز وإدارة الخدمات المختارة.
* **Internet Connection Check:** نظام لمراقبة حالة الاتصال بالإنترنت.
